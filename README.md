# 10자 사원 주식회사

2026 KHU AI Challenge 출품작. 직급별 글자 수로 직원을 만들어 회사를 운영하는 AI 텍스트 배틀 게임입니다.

**한 명씩 혼자 플레이하고, 1년(4분기) 누적 수익으로 순위를 겨룹니다. 같은 대결의 사장님들은 모두 같은 업종입니다.**

**게임 흐름**
1. **창업**: 닉네임 → 업종 → 회사 세부정보·이름·사훈 → 자금 출처 선택 → **봉투를 한 번 열어 회사 통장에 입금**
   - 부모님 돈: 8,000만원, 통장이 마이너스가 되면 긴급 용돈 4,000만원을 딱 한 번 지원
   - 알바로 모은 돈: 1억원, 후보 직원들의 시작 충성심 +2
   - 로또 당첨금: 6,000만원·1억원·1억 4,000만원 중 하나. 개봉 후 출처·금액이 고정되고 새로고침·이어하기로 다시 뽑지 않음
2. **ChatKHU**: 창업 뉴스, 4분기 이벤트(위기 2, 기회 2), 면접 후보 18명의 이름·자기소개·면접 답변
3. **면접**: 임원·부장·차장·과장·대리·사원마다 후보 3명 중 1명 (또는 공석). 지원 동기·실수 대처·지시 전달 중 질문을 골라 답변을 하나 이상 들은 뒤 채용. 추가 질문은 후보 성격에 따라 게임이 답하며 AI를 별도로 호출하지 않음. 능력·운·MBTI·안정형/회피형 비율은 보이고 정직도는 숨김. 능력이 좋을수록 연봉이 비쌈
4. **분기마다**: 투자 여부 선택 → 사장이 100자로 지시 → ChatKHU가 직원들을 연기 → 보고·추리 단서를 비교해 **🔍 파고들기 / 👏 칭찬하기** → 진실 공개 → **급여·투자·매출을 통장에서 정산**
   - 칭찬 + 잘함 → 충성심 +1 · 칭찬 + 못함 → 불이익 −3,000만원
   - 파고듦 + 잘함 → 충성심 −1 (0이면 퇴사) · 파고듦 + 못함 → 불이익 없음
   - **그대로 운영 / 1,000만원 투자** 중 선택. 성과 60점 이상이면 투자금 1,600만원 회수(+600만원), 미달이면 500만원 회수(−500만원). 급여·회식비를 확보한 남은 현금으로만 투자
   - 3개월치 급여를 분기 말 한 번 자동 지급. 분기 순이익 = 성과 × 100만원 + 투자 회수 − 투자 원금 − 급여 − 불이익 − 회식비
   - **잔액 = 창업자금 + 누적 순이익 + 긴급 용돈**. 자금 지원은 매출·순이익에 포함하지 않음. 잔액이 부족하면 마이너스로 표시하고 투자·회식을 제한하며, 4분기까지 운영은 계속
   - 전원 퇴사 후에도 4분기까지 결산. 영업 중단 분기의 매출·급여·투자는 0원, 임대료·위약금 손실은 1억원. 최대 분기 손실 9,400만원(투자·회식 포함)보다 커서 중단으로 적자를 피할 수 없음
   - **사장 필살기: 세 가지 중 판당 딱 한 번**. 지시 전 회식(300만원·재직 직원 충성심 +2, 최대 10) 또는 직통 전화(가장 낮은 직급에게만 지시, 전 직원 급여는 유지), 보고 후 현장 출동(실제 업무·감사 내용·성과 확인)
   - 마지막 분기 안전·도전 선택은 매 분기의 투자 선택으로 통합. 투자·추리 단서·그래프에는 추가 AI 호출 없음
5. **분기·연간 그래프**: 창업~4분기 통장 잔액은 꺾은선, 분기별 수입·지출은 막대로 표시. **분기 버튼을 누르면 해당 분기의 기초 잔액·급여·투자 출금/회수·지원금·마감 잔액**을 확인. 마이너스 잔액도 표시
6. **1년 결산**: 최종 잔액과 순이익을 나란히 표시하고 **순위는 순이익으로만 비교**. 거짓말왕·충성심·경영 방식별 엔딩과 결산 복사 기능 제공

**순위표**: 오른쪽 위 🏆 버튼. 게임한 노트북 브라우저에 저장되므로 노트북 한 대로 돌려가며 하세요. 다른 기기에서 같은 업종으로 겨루려면 순위표 화면의 **대결 링크**로 접속합니다. 연습 모드가 섞인 판은 순위에 들어가지 않습니다. ChatKHU 답을 복사·붙여넣기로 넣은 단계가 있는 판도 연습으로 칩니다. 시연 전 테스트 기록은 순위표 맨 아래 **순위표 초기화**(두 번 클릭)로 지우세요. 초기화하면 대결 업종도 새로 뽑습니다.

**로그인**: 공유 저장소가 켜져 있으면 처음 화면이 로그인입니다. 전시회 관람객은 **가입 없이 닉네임만으로 바로 시작**(게스트, 순위표에 `닉네임(손님)`)할 수 있습니다. 아이디가 곧 닉네임이라 겹치지 않고(대소문자 무시), 하던 게임은 어느 기기에서든 이어서 할 수 있습니다(`js/account.js`). 순위 기록은 로그인한 아이디로만 저장됩니다.

**공유 순위표**: 팀 서버에 저장소(KV)를 연결하면 모든 기기가 순위표 하나와 대결 업종 하나를 같이 씁니다(`js/board-sync.js`). 연결 전이나 서버 오류 때는 각 기기에 저장합니다. 초기화에는 관리자 코드가 필요합니다. 설정법은 [`docs/cloudflare-setup.md`](docs/cloudflare-setup.md) 아래쪽.

순위는 **현재 대결과 같은 업종**끼리 표시하며, 4분기를 모두 결산한 판만 기록합니다. 팀 서버 공유 저장소가 켜져 있으면 모든 기기의 기록이 한 순위표에 모이고, 꺼져 있으면 각 기기에만 저장됩니다(이때 공유 링크는 업종을 맞추는 용도). 다른 업종 링크로 바꾸어도 기존 업종의 기록은 보관됩니다.

이전 경제 규칙의 기록은 보관하되 새 통장 규칙 순위표와 분리합니다. 기존 규칙으로 저장된 게임은 이어하기 화면에서 안내 후 새로 시작합니다. 로그인한 사용자의 봉투 금액·면접·투자·필살기·지시 초안은 기기 내 즉시 보관하고 서버에 순서대로 저장해 이어하기에 반영합니다. 게스트는 기존처럼 이어하기를 지원하지 않습니다.

규칙을 수정한 뒤에는 `node --test tests/game.test.js`로 면접·칭찬/추궁·퇴사·순위표를 확인할 수 있습니다. Node.js 기본 기능만 사용하며 게임 실행에는 필요하지 않습니다.

**ChatKHU 연결**: 팀 중간 서버(Cloudflare Worker)가 팀 키로 ChatKHU를 대신 불러서, 플레이어와 심사위원은 키 없이 플레이합니다. 설정법은 [`docs/cloudflare-setup.md`](docs/cloudflare-setup.md). 팀원이 자기 키로 테스트하려면 오른쪽 위 🔌 버튼에서 개인 키를 넣으면 됩니다.

ChatKHU 쓰는 법은 [`prompts/chatkhu.md`](prompts/chatkhu.md)에 있습니다.

## 매번: 작업 순서 (이것만 기억하세요)

```
① 받기 (Pull)  →  ② 작업  →  ③ 기록 (Commit)  →  ④ 올리기 (Push)
```

### ① 받기: 작업 시작 전에 무조건

GitHub Desktop 위쪽 **Fetch origin** → **Pull origin**이 나오면 누르기.
다른 사람이 올린 최신 코드를 받아옵니다.

### ② 작업

### ③ 기록 (Commit)

GitHub Desktop 왼쪽에 바뀐 파일이 보입니다.
왼쪽 아래 **Summary**에 무엇을 했는지 한 줄 쓰고 **Commit to main**.

좋은 예: `채용 화면에 예산 막대 추가` · 나쁜 예: `수정`

### ④ 올리기 (Push)

> **작게 자주 올리세요.** 1~2시간마다 한 번. 하루 모아서 올리면 충돌이 커집니다.

## 문제가 생겼을 때

### Push가 안 되고 "Pull 먼저 하라"고 할 때

다른 사람이 먼저 올린 것입니다. **Pull origin**을 누른 뒤 다시 **Push origin**.

### 충돌(conflict)이 났을 때

같은 파일의 같은 부분을 두 사람이 고친 것입니다.

1. 당황하지 말고 단톡방에 알리기
2. 파일을 열면 이런 표시가 있습니다.
   ```
      내가 쓴 내용
   
   팀원이 쓴 내용
      ```
3. 둘 중 맞는 것만 남기고 `<<<<<<<`, `=======`, `>>>>>>>` 줄을 모두 지운 뒤 저장
4. GitHub Desktop에서 Commit → Push

### 망한 것 같을 때

**절대 폴더를 지우고 새로 받지 마세요.** 올리지 않은 작업이 사라집니다. 먼저 단톡방에 화면 캡처를 올리세요.
