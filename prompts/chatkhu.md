# ChatKHU 사용법 (담당 C)

게임 안에서 AI가 하는 일은 모두 ChatKHU가 합니다. 방법은 두 가지입니다.

1. **자동 연결 (추천)**: 오른쪽 위 🔌 버튼에서 ChatKHU **API Gateway** 키를 한 번 저장하면, 이후 ChatKHU 단계가 자동으로 진행됩니다. 결과 화면에 사용한 모델 이름이 표시됩니다.
2. **복사·붙여넣기**: 자동 연결이 안 될 때. 게임이 만든 요청문을 ChatKHU 채팅창에 붙여넣고, 답을 다시 게임에 붙여넣습니다. 붙여넣기로 진행한 단계가 하나라도 있으면 그 판은 **연습으로 쳐서 순위에 기록되지 않습니다**.

## API 키 주의 (중요)

- 키는 ChatKHU → API Gateway에서 만들고, **만든 직후 한 번만 보이니** 바로 복사해 두세요.
- 키는 **게임 화면에만** 입력합니다. 코드, GitHub, 단톡방에 절대 올리지 마세요. 저장소가 공개라 올리는 순간 누구나 우리 크레딧을 씁니다.
- 키는 입력한 그 브라우저에만 저장됩니다. 공용 컴퓨터나 전시 부스에서는 끝나고 **저장된 키 지우기**를 누르세요.
- 실수로 노출됐으면 API Gateway에서 바로 해지하고 새로 만드세요.
- "브라우저에서 ChatKHU에 접속하지 못했어요"가 뜨면 ChatKHU가 웹페이지에서의 직접 호출을 막는 것일 수 있습니다. 그때는 복사·붙여넣기로 하고 팀장에게 알려 주세요.

## 한 판에 ChatKHU를 기본 6번, 업종 다시 뽑기 포함 최대 7번 씁니다

| 단계 | ChatKHU가 하는 일 | 요청문 만드는 곳 (`js/ai.js`) |
|---|---|---|
| 업종 뽑기 | 랜덤 키워드로 엉뚱한 업종 하나 (대결의 첫 사람만) | `buildIndustryRequest()` |
| 창업 | 창업 뉴스, 4분기 이벤트, 면접 후보 18명의 이름·자기소개·답변 | `buildFoundingRequest()` |
| 분기 x4 | 직원별 지시 전달(거짓말 여부 포함), 부풀린 보고, 실제로 한 일, 성과 점수, 뉴스, 파고들었을 때 드러나는 사실 | `buildEventRequest()` |

후보의 능력치(능력·운·정직·MBTI·애착유형)는 공정하도록 게임이 정하고, ChatKHU는 그 능력치에 맞게 말과 행동을 연기합니다.

직통 전화를 쓰면 이벤트 요청의 staff에는 가장 낮은 직급 한 명만 들어갑니다. 회식과 알바 자금으로 오른 충성심도 요청에 반영됩니다. AI는 순수 업무 성과만 판정하며, 투자금 출금·회수·급여·긴급 용돈·잔액 그래프·필살기 비용·엔딩은 게임에서 처리하므로 추가 호출이 없습니다. 추리 단서는 같은 이벤트 답의 clues에 ChatKHU가 경우별(low·mid·high, lie·honest)로 미리 쓰고, 게임이 실제 결과에 맞는 칸을 고릅니다. 빠지거나 답이 새는 칸은 준비된 문장으로 바뀝니다.

요청문 안에 규칙과 출력 형식이 다 들어 있어서, 일반 채팅창에 그냥 붙여넣어도 됩니다.

## 복사·붙여넣기 하는 방법

1. 게임에서 **요청문 복사하기**
2. [chat.khu.ac.kr](https://chat.khu.ac.kr)에서 새 대화를 열고 붙여넣기
3. ChatKHU 답변 전체를 복사해 게임의 칸에 붙여넣고 **결과 적용**
4. "JSON 형식이 깨졌어요"가 나오면 ChatKHU에 `형식에 맞게 JSON만 다시 출력해줘`

## 해 볼 실험 (서식4 재료, 심사 30점)

결과를 `docs/ai-log.md`에 꼭 적어 주세요.

- **모델 비교**: 게임의 'API 키·모델 바꾸기'에서 모델만 바꿔 같은 판을 돌려 비교. 글자 수를 잘 지키는지, 성격 연기가 웃긴지, JSON 형식을 잘 지키는지
- **사훈 효과**: 다른 조건은 같게 두고 사훈만 바꿔서 결과가 달라지는지
- **정직도 효과**: 정직도 낮은 직원이 실제로 거짓말(🤥)을 더 많이 하는지 세어 보기
- **일관성**: 같은 판을 세 번 돌려서 점수가 얼마나 흔들리는지
- **요청문 고치기**: 결과가 마음에 안 들면 `js/ai.js`의 요청문 문구를 고치고, 고치기 전과 후를 기록. 예: "보고가 안 부풀려져서 '위로 갈수록 부풀려라'에 예시 추가"

게임 결과 화면에 "AI가 글자 수를 N번 넘겨서 잘랐어요"가 나오면 그것도 기록하세요. 모델별로 세어 두면 좋은 비교 자료가 됩니다.
